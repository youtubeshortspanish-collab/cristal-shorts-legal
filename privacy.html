Español

Qué es. Cristal Shorts es una herramienta personal que usa un único usuario (el propietario del canal) para gestionar su propio canal de YouTube. Utiliza los Servicios de API de YouTube.

Condiciones de YouTube y privacidad de Google. Al usar esta herramienta se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Datos a los que accede. Solo datos del canal del propietario: lista de vídeos, metadatos (título, descripción, etiquetas, visibilidad, fecha de publicación), listas de reproducción y estadísticas agregadas del canal (visualizaciones, retención, horas de visualización). No accede a datos de espectadores individuales ni de otros usuarios.

Para qué los usa. Para subir y programar vídeos, crear y ordenar listas de reproducción, actualizar descripciones y elaborar un informe semanal privado de rendimiento.

Dónde se guardan. El permiso de acceso (token OAuth) se guarda en el ordenador del propietario y, cifrado, en los secretos de su repositorio privado de GitHub. Los identificadores de vídeos y listas y las estadísticas se guardan en ese repositorio privado. Los datos de la API de YouTube Analytics y las estadísticas del canal se conservan mientras el acceso siga autorizado, comprobando la autorización al menos cada 30 días; el resto de datos de los Servicios de API de YouTube se actualiza o elimina en un plazo máximo de 30 días.

Con quién se comparten. Con nadie. No se venden, no se ceden a terceros y no se usan para publicidad. No se usan cookies, no se rastrean dispositivos y no se muestra contenido de terceros.

Cómo revocar el acceso y borrar los datos. En cualquier momento, desde la página de permisos de seguridad de Google. Al revocarlo, la herramienta deja de poder acceder. Los datos almacenados se eliminan en un máximo de 7 días tras la revocación o tras pedirlo por correo al contacto de abajo.

English

What it is. Cristal Shorts is a personal tool used by a single user (the channel owner) to manage their own YouTube channel. It uses YouTube API Services.

YouTube Terms and Google Privacy. By using this tool you are bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

Data accessed. Only the owner's channel data: video list, metadata (title, description, tags, privacy status, publish time), playlists and aggregated channel analytics (views, retention, watch time). It does not access data of individual viewers or any other users.

How it is used. To upload and schedule videos, create and order playlists, update descriptions and produce a private weekly performance report.

Storage. The access permission (OAuth token) is stored on the owner's computer and, encrypted, in the secrets of their private GitHub repository. Video and playlist IDs and analytics are stored in that private repository. YouTube Analytics API data and channel statistics are kept while access remains authorized, with the authorization re-checked at least every 30 days; all other data obtained from YouTube API Services is refreshed or deleted within 30 days.

Sharing. None. Data is not sold, not shared with third parties and not used for advertising. No cookies are used, no devices are tracked and no third-party content is served.

Revoking access and deleting data. At any time via the Google security settings permissions page. After revocation the tool can no longer access the account. Stored data is deleted within 7 days of revocation or of a request sent to the contact below.
